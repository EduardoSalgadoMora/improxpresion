# Fuentes

Sube aquí el archivo de la fuente **Alphakind** con el nombre `alphakind` y su extensión:

- `alphakind.woff2`  ← ideal (la más ligera para web)
- o `alphakind.ttf` / `alphakind.otf` / `alphakind.woff` (cualquiera vale)

En cuanto esté subida, el **menú** de la cabecera usará esa fuente automáticamente
(mientras no esté, usa Poppins como respaldo, así que no se rompe nada).

Si tu archivo tiene otro nombre, súbelo igual y avísame para ajustar el código.
